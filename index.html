1. 社員情報の入力

評価対象者を入力してください。入力内容と評価結果は、この端末のブラウザ内に保存されます。

2. 基準となるLevelを選択

通常評価では、選んだLevelを中心に、1つ前のLevel → 選んだLevel → 1つ先のLevelの昇順で評価します。Level1は1→2、Level7は6→7です。

標準評価の順番
S＝4点A＝3点B＝2点C＝0点－＝2点

このLevelの「知識」と「技術」をそれぞれ読み、S・A・B・C・－から1つ選択してください。

S：期待を大きく超え、模範であるA：十分に満たしているB：一部に未達ありC：著しく不足－：該当せず（2点換算）

4. 評価結果

評価したLevelを一覧で表示します。知識・技術は別々に得点化しています。

S＝4点A＝3点B＝2点C＝0点－＝2点

任意のLevelを追加評価

標準フロー：1つ前のLevel → 選択Level → 1つ先のLevelの昇順。3Level評価で一番高いLevelが最高得点の場合は次のLevelを追加評価し、上位Levelで得点が下がった時点で現在のLevelを確定します。各項目の知識・技術は、S/A/B/C/－を直接選択します。
